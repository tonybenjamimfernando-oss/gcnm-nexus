# GCNM Nexus — proposta de redefinição visual (prévia não publicada)

## Direção criativa
As referências partilhadas servem de orientação, não de assets para copiar: interface móvel de cartões translúcidos, diagrama de módulos conectados, linhas âmbar de hierarquia e paleta esmeralda/polar.

## Linguagem visual
- Base noturna verde-profunda com halos discretos; retirar fundos decorativos dependentes de ficheiros não confirmados.
- Vidro esmeralda com contraste alto e contornos suaves para cartões e navegação.
- Âmbar/dourado reservado para preços, chamadas à ação, ranking e estados de destaque.
- Microanimações de baixa amplitude; respeitar `prefers-reduced-motion`.
- Layout de tendências vertical no desktop e carrossel horizontal compacto no telemóvel.
- A página de exploração continua a privilegiar pesquisa, filtros e resultados; o portal cósmico fica abaixo dos filtros.

## Princípios de implementação
- Não copiar o mockup de saúde: adaptar apenas os padrões de cartões, navegação inferior responsiva e hierarquia de informação ao comércio.
- Não usar as imagens com marca d'água como assets de produção.
- Preservar rotas, modo de demonstração e funcionalidades existentes.
- Esta alteração fica numa branch de pré-visualização. Não integrar em `main` nem publicar no GitHub Pages sem autorização explícita.
